# Viikko1

## Start

Kirjataan hyväksymiskriteerit user storyihin.

## Stop

Lopetetaan tapaamisten väliin jättäminen ilman, että sanoo mitään.

## Continue

Tehdään asiat alusta loppuun saakka. Merkkaa ensin, että task on työn alla, ja lopuksi, että task on valmis.

## More of

Lisää kommunikaatiota ylipäänsä. Kysymyksiä siitä, mitä tulisi tehdä. Kerro, mitä teet seuraavaksi. Assignaa itsesi taskeihin.

Lisää backlogin tarkistamista.

# Less off

Ei pull requesteja, jos varma, että koodi toimii.

# Viikko2

## Start

Kiinnitetään enemmän huomiota koodin laatuun.

## Stop

Ei mitään, mikä tarvitsisi lopettaa.

## More of

Käytetään gitissä brancheja, jos tarvetta, eli jos tekee isompia muutoksia koodiin. Myös enemmän kommunikaatiota siitä, mitä on tekemässä.

## Less of

Vähemmän unittestejä, testataan suurin osa asioista robot testeillä.

## Viikon 1 parannuskohteiden toteutuminen

Kirjataan hyväksymiskriteerit user storyihin toteutui.
Ei tehdä turhia pull requesteja toteutui.
Merkitään taskit in progress toteutui osittain. Kaikilla ei ollut muokkausoikeuksia aluksi, nyt oikeudet löytyvät kaikilta.
